# Data Breach Response Plan

**Carters Care Platform**  
**Version:** 1.0  
**Effective Date:** April 2025  
**Review Cycle:** Annual

---

## 1. Purpose

This plan establishes procedures for identifying, containing, assessing, and responding to data breaches affecting the Carters Care Platform, in compliance with the Notifiable Data Breaches (NDB) scheme under the Privacy Act 1988 (Cth).

---

## 2. Scope

This plan applies to:
- All personal information held by Carters Care
- All staff, contractors, and third-party providers
- All systems and platforms operated by Carters Care

---

## 3. Definitions

| Term | Definition |
|------|------------|
| **Data Breach** | Unauthorized access, disclosure, loss, or theft of personal information |
| **Eligible Data Breach** | A breach likely to result in serious harm to affected individuals |
| **Serious Harm** | Physical, psychological, emotional, financial, or reputational harm |
| **OAIC** | Office of the Australian Information Commissioner |

## 5. Response Phases

### Phase 1: Identification & Containment (0-4 hours)

**Immediate Actions:**
1. Document the suspected breach (time, nature, scope)
2. Notify the Privacy Officer immediately
3. Contain the breach:
   - Revoke compromised credentials
   - Isolate affected systems
   - Block suspicious IP addresses
   - Disable compromised accounts
4. Preserve evidence (logs, screenshots)
5. DO NOT delete or modify evidence

**Containment Checklist:**
- [ ] Affected systems identified
- [ ] Unauthorized access blocked
- [ ] Credentials rotated
- [ ] Logs preserved
- [ ] Initial incident record created

### Phase 2: Assessment (4-24 hours)

**Determine:**
1. **What data was affected?**
   - Types of personal information
   - Volume of records
   - Sensitivity level

2. **Who is affected?**
   - Number of individuals
   - Categories (clients, staff, etc.)
   - Jurisdictions involved

3. **How did it occur?**
   - Attack vector
   - Vulnerabilities exploited
   - Timeline of events

4. **Is it an Eligible Data Breach?**
   - Is serious harm likely?
   - Consider: type of data, circumstances, who has access

**Eligible Breach Indicators:**
- Health or care information exposed
- Financial information compromised
- Identity documents accessed
- Malicious actor involved
- Data published publicly

### Phase 3: Notification (24-72 hours)

**If Eligible Data Breach Confirmed:**

#### 3.1 OAIC Notification (within 30 days, ideally 72 hours)
Submit via: www.oaic.gov.au/privacy/notifiable-data-breaches/

Include:
- Organization details
- Description of the breach
- Types of information involved
- Number of affected individuals
- Recommendations for affected individuals
- Contact information

#### 3.2 Affected Individuals Notification
**Method:** Direct communication (email preferred)

**Content:**
- Description of the breach
- Types of their information involved
- Steps we are taking
- Steps they should take
- Contact information for questions

**Template:**
```
Subject: Important Privacy Notice from Carters Care

Dear [Name],

We are writing to inform you of a data incident that may have affected your personal information.

What happened: [Brief description]

What information was involved: [List types]

What we are doing: [Actions taken]

What you can do: [Recommendations]

We sincerely apologize for any concern this may cause. If you have questions, please contact us at privacy@carterscare.com.au or [phone].

Regards,
Carters Care Privacy Team
```

#### 3.3 NDIS Commission Notification (if applicable)
For incidents involving NDIS participants, notify the NDIS Quality and Safeguards Commission within 24 hours if the breach relates to:
- Participant safety
- Reportable incidents
- Systemic issues

Portal: www.ndiscommission.gov.au

### Phase 4: Remediation (1-4 weeks)

1. **Technical Remediation**
   - Patch vulnerabilities
   - Update security controls
   - Implement additional monitoring
   - Conduct security review

2. **Process Improvements**
   - Update policies if needed
   - Enhance training
   - Review access controls
   - Improve detection capabilities

3. **Documentation**
   - Complete incident report
   - Document lessons learned
   - Update risk register
   - Archive evidence securely

### Phase 5: Review (4-8 weeks)

1. Conduct post-incident review
2. Update this response plan if needed
3. Report to management/board
4. Schedule follow-up security assessment

## 6. Escalation Matrix

| Severity | Criteria | Escalation |
|----------|----------|------------|
| **Critical** | >1000 records, health data, malicious attack | CEO + Legal + OAIC |
| **High** | 100-1000 records, sensitive data | Privacy Officer + Management |
| **Medium** | <100 records, limited sensitivity | Privacy Officer |
| **Low** | Near-miss, no data accessed | Technical Lead |
