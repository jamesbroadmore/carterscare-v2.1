# 1. Acceptable Use Policy

## Purpose
This policy defines acceptable use of the Carter's Care Platform and related technology resources.

## Scope
All employees, contractors, and authorized users of the platform.

## Policy

### 1.1 Account Security
- Use strong, unique passwords (minimum 12 characters)
- Enable multi-factor authentication
- Never share login credentials
- Report suspected account compromise immediately
- Lock your device when unattended

### 1.2 Data Handling
- Access only data necessary for your role
- Do not export data without authorization
- Do not store client data on personal devices
- Do not share client information outside the platform
- Report any data loss or exposure immediately

### 1.3 Device Security
- Keep devices updated with latest security patches
- Use antivirus software (Windows Defender acceptable)
- Enable device encryption (BitLocker/FileVault)
- Do not install unauthorized software
- Use secure networks only (avoid public WiFi)

### 1.4 Prohibited Activities
- Accessing records without legitimate purpose
- Sharing login credentials
- Circumventing security controls
- Storing platform data on personal cloud storage
- Using the platform for personal purposes
- Attempting to access unauthorized areas

### 1.5 Incident Reporting
Report immediately to your supervisor:
- Suspected security breaches
- Lost or stolen devices
- Phishing attempts
- Unusual system behavior
- Privacy concerns

## Consequences
Violations may result in:
- Disciplinary action
- Termination of access
- Legal action (serious violations)

# 2. Confidentiality Agreement

## Purpose
To protect sensitive information accessed through the Carter's Care Platform.

## Agreement

I, ________________________, acknowledge and agree that:

### 2.1 Confidential Information
I may have access to confidential information including:
- Client personal and health information
- Staff personal information
- Business and financial information
- System security information

### 2.2 Obligations
I agree to:
- Keep all confidential information strictly confidential
- Access only information required for my role
- Not disclose confidential information to unauthorized persons
- Not use confidential information for personal benefit

- Required by law

This agreement remains in effect:
- During my employment/engagement
- Indefinitely after my employment/engagement ends

I understand unauthorized disclosure may result in:
- Disciplinary action up to termination

# 3. Security Awareness Guidelines

## Overview
These guidelines help protect our platform and the people we serve.

## Password Security

### Do:
✅ Use a password manager (1Password, Bitwarden recommended)  
✅ Create unique passwords for each account  
✅ Use passphrases (e.g., "correct-horse-battery-staple")  
✅ Enable MFA whenever available  
✅ Change passwords if you suspect compromise  

### Don't:
❌ Reuse passwords across accounts  
❌ Write passwords on sticky notes  
❌ Share passwords with anyone  
❌ Use personal information in passwords  
❌ Save passwords in browsers (use password manager instead)  

## Phishing Awareness

### Red Flags:
⚠️ Urgent requests for action  
⚠️ Requests for passwords or sensitive data  
⚠️ Unexpected attachments  
⚠️ Misspelled sender addresses  
⚠️ Generic greetings ("Dear User")  
⚠️ Threats or pressure tactics  

### If Suspicious:
1. Don't click links or attachments
2. Don't reply
3. Report to IT/supervisor
4. Delete the email

## Device Security

### Keep Updated:
- Operating system
- Web browser
- Antivirus software
- Applications

### Physical Security:
- Lock screen when away (Win+L or Cmd+Ctrl+Q)
- Don't leave devices unattended
- Store devices securely
- Report lost/stolen devices immediately

### Network Security:
- Avoid public WiFi for work
- If must use public WiFi, use VPN
- Ensure home WiFi uses WPA3/WPA2
- Don't access platform from untrusted computers

## Data Protection

### Client Data:
- Access only what you need
- Don't take screenshots of client info
- Don't discuss clients in public
- Don't store client data locally

### Sharing:
- Share only within the platform
- Verify recipient before sharing
- Use platform features, not email/text

## Incident Response

### Report Immediately:
🚨 Suspected unauthorized access  
🚨 Lost or stolen devices  
🚨 Accidentally shared data  
🚨 Suspicious emails or calls  
🚨 System behaving strangely  

### How to Report:
1. Contact supervisor immediately
2. Email security@carterscare.com.au
3. Document what happened
4. Preserve any evidence

## Quiz Questions (Self-Assessment)

1. What should you do if you receive an urgent email asking for your password?
2. How often should you update your device's operating system?
3. What's the minimum recommended password length?
4. Who should you report a suspected security incident to?
5. Is it okay to use public WiFi to access the platform?

# 4. Onboarding Security Checklist

## For New Staff

### Before First Day
- [ ] Background check completed
- [ ] Confidentiality agreement signed
- [ ] Acceptable use policy signed

### First Day
- [ ] Account created with appropriate role
- [ ] Temporary password provided securely
- [ ] MFA setup completed
- [ ] Security awareness overview provided
- [ ] Emergency contacts provided

### First Week
- [ ] Password changed from temporary
- [ ] Platform training completed
- [ ] Security guidelines reviewed
- [ ] Questions answered
- [ ] Access verified appropriate to role

### First Month
- [ ] Full platform proficiency
- [ ] Security quiz completed
- [ ] Any access issues resolved
- [ ] Feedback on security processes

## For Managers (New Staff Setup)

### Access Request
- [ ] Role clearly defined
- [ ] Minimum necessary access identified
- [ ] Approval documented
- [ ] Start date confirmed

### Account Creation
- [ ] Account created in correct organization
- [ ] Correct role assigned
- [ ] MFA enforcement confirmed
- [ ] Welcome email sent

### Training
- [ ] Security training scheduled
- [ ] Platform training scheduled
- [ ] Supervisor assigned

### Verification
- [ ] First login confirmed
- [ ] MFA working
- [ ] Access appropriate
- [ ] Documents signed and filed

## Offboarding Checklist

### Immediate (Last Day)
- [ ] Account disabled
- [ ] Sessions terminated
- [ ] Access revoked
- [ ] Devices returned (if applicable)
- [ ] Exit interview includes security reminder

### Within 24 Hours
- [ ] Account fully deactivated
- [ ] Any shared passwords changed
- [ ] Access logs reviewed for anomalies
- [ ] Manager notified of completion

### Within 7 Days
- [ ] Audit of recent activity
- [ ] Documentation updated
- [ ] HR records updated
